# 내 영화 티어리스트 · 미션 1

**설치 없이 HTML 파일 하나를 열어 영화를 등급별로 정리하는 페이지입니다.**

## 바로 사용하기
1. `영화_A_초안.html`을 다운로드합니다. GitHub에서는 파일의 **Raw / Download raw file**로 원본을 저장하세요.
2. 파일을 더블 클릭해 Chrome·Edge 같은 브라우저로 엽니다. 확장자가 `.html.txt`가 아닌 `.html`인지 확인하세요.
3. 영화를 클릭한 뒤 **S / A / B / C / 미분류** 버튼을 누릅니다. 마우스로 끌어서 옮겨도 됩니다.
4. 새 영화는 제목을 쓰고 **추가** 또는 Enter를 누릅니다.
5. **처음으로**는 확인을 누르면 추가한 영화와 배치를 지우고 기본 8편으로 돌아갑니다.

포스터·회원가입·서버·외부 연결은 필요 없습니다. 기록은 브라우저에 저장됩니다. **같은 브라우저에서 같은 파일 경로**로 열어 주세요. 다른 기기·브라우저에 동기화되지 않으며, 저장 권한 차단·시크릿 모드·파일 이동·브라우저 데이터 삭제 시 유지되지 않을 수 있습니다. 저장 실패는 화면에 표시합니다.

## 확인한 것과 아직 못 한 것
- **통과:** 기본 목록, 선택·이동 이벤트, 추가·중복 방지, 저장자료 복원, 초기화, 저장 실패·잘못된 저장자료 처리 등 **Node 모의 DOM 테스트 12개**. 소스 리뷰에서도 확정 결함은 발견되지 않았습니다.
- **미검증:** 이 실행 환경에서 Chromium이 운영체제 권한 오류로 시작되지 않아 실제 파일 재열기·화면·모바일·키보드·드래그 테스트는 완료하지 못했습니다. 테스트 코드가 있다는 것과 실제 통과는 다릅니다.
- **미생성:** 다른 회사 AI는 로그인 단계에서 막혀 `영화_B_초안.html`이 없습니다. 같은 AI로 B를 대신 만들거나 A/B 비교를 꾸미지 않았습니다.
- **미확보:** 실제 주요 대화 캡처 이미지. 요청 텍스트·로그는 캡처 이미지가 아닙니다.
- **미업로드:** GitHub API DNS 연결 실패 및 인증 확인 실패로 푸시하지 못했습니다. 아직 제출 요건 전체가 완료된 것은 아닙니다.
- 질문은 사용자 지시에 따라 생략했습니다. 교육 과정의 ‘AI가 질문하고 내가 답하기’ 요건과 다른 진행임을 기록했습니다.

## 테스트 다시 실행
Node.js가 있다면 의존성 설치 없이 실행합니다.
```sh
node --test scripts/logic.test.cjs
```
실제 브라우저 테스트는 기존 Playwright와 Chromium 경로를 지정해 실행할 수 있습니다. 이 두 도구는 HTML 사용에 필요하지 않습니다.
```sh
PLAYWRIGHT_MODULE=/설치경로/playwright CHROMIUM_PATH=/설치경로/chromium node scripts/verify.cjs
```
브라우저 검증 실패 로그는 `evidence/브라우저_검증.txt`, 로직 결과는 `evidence/로직_검증.tap`에 있습니다.

## GitHub 등록 상태
원격 등록이 가능해지면 `mission1-movie-tierlist`라는 **비공개** 저장소로 올리도록 시도했습니다. 실패 원문은 `evidence/GitHub_업로드.txt`에 남겼습니다. 현재 작업 폴더의 `.git` 생성도 권한으로 막혀, 허용된 임시 폴더에서 로컬 커밋을 만들고 `미션1_저장소.bundle`로 보관했습니다. 이 파일은 GitHub 업로드 완료를 뜻하지 않습니다. 제출용 저장소 공개 범위는 교육 운영 안내에 맞춰야 합니다. 사용자 계정 비밀번호·토큰은 저장소에 넣지 않았습니다.


### 로컬 Git 기록 복원
Git이 설치된 다른 폴더에서 아래 명령을 실행하면 파일과 첫 커밋을 함께 복원할 수 있습니다.
```sh
git clone 미션1_저장소.bundle mission1-movie-tierlist
```
번들 없이 HTML 파일만 열어 사용해도 됩니다.
