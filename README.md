# 내 영화 티어리스트 · 미션 1

영화를 S·A·B·C·미분류로 정리하는 단일 HTML 앱입니다.

## 사용 방법
1. **[영화_A_초안.html](영화_A_초안.html)** 을 다운로드합니다. GitHub에서는 Download raw file을 사용하세요.
2. Chrome·Edge 등에서 파일을 엽니다.
3. 영화를 선택하고 등급 버튼을 누르거나 드래그해 이동합니다.
4. 제목을 입력하고 Enter로 추가합니다. 처음으로 버튼은 확인 후 최초 8편을 복원합니다.

같은 브라우저·같은 파일 경로에서 자동 저장됩니다. 다른 기기와 동기화되지 않으며, 시크릿 모드·저장 차단·파일 이동·브라우저 데이터 삭제 시 유지되지 않을 수 있습니다. 설치·서버·로그인은 필요 없습니다.
