# 내 영화 티어리스트 · 미션 1

설치 없이 HTML 파일 하나로 영화를 S/A/B/C/미분류에 정리합니다.

## 바로 사용하기
1. **[영화_A_초안.html](영화_A_초안.html)** 을 다운로드합니다. GitHub에서는 Raw / Download raw file을 사용합니다.
2. 파일을 Chrome·Edge 등으로 엽니다. 확장자는 `.html`이어야 합니다.
3. 영화 클릭 후 등급 버튼을 누르거나 카드를 끌어 이동합니다. 제목 입력 후 Enter로 추가합니다.
4. 처음으로 버튼은 확인 후 최초 8편으로 복원합니다.

브라우저 localStorage에 자동 저장합니다. 같은 브라우저·같은 파일 경로에서 사용하세요. 다른 기기 동기화는 없으며 시크릿 모드·저장 차단·파일 이동·브라우저 데이터 삭제에 따라 기록이 유지되지 않을 수 있습니다. 포스터·서버·외부 폰트·로그인은 필요 없습니다.

## 최종 결과
- **A (Codex): 최종 선택.** 로직 12/12, 실제 Chromium 브라우저 13/13 통과.
- **B (Upstage Solar `solar-pro4-260806`): 비교용 초안.** 실제 브라우저 10/14 통과. 80자 초과 입력, 키보드 이동, 미분류 이동 버튼, 손상 저장자료 안내에서 실패. 모바일 등급 머리글 겹침도 확인했습니다.
- 동일한 요청·기획서로 두 회사의 AI를 사용했습니다. 선택 근거와 세부 결과는 [미션1_기록.md](미션1_기록.md)에 있습니다.
- 스크린샷은 실제 HTML 렌더입니다. 대화 화면 캡처나 동료 평가를 대신하지 않습니다.

## 파일 안내
- `기획서.md`: 다섯 항목 기획과 완성 기준
- `영화_A_초안.html`: 최종 사용 파일, 수정 없이 채택
- `영화_B_초안.html`: Upstage 원본, 알려진 실패가 있는 비교 자료
- `미션1_기록.md`: 비교 결과·선택 이유·제한
- `코랩세션_리포트_사전작성.md`: 확인된 내용만 작성한 세션 준비 자료
- `evidence/`: 실제 API 응답, 테스트 결과, 렌더 캡처, 업로드 검증
- `scripts/`: 재검증 코드. HTML 사용에는 필요하지 않음

## 재검증
```sh
node --test scripts/logic.test.cjs
PLAYWRIGHT_MODULE=/설치경로/playwright CHROMIUM_PATH=/설치경로/chromium node scripts/verify.cjs
PLAYWRIGHT_MODULE=/설치경로/playwright CHROMIUM_PATH=/설치경로/chromium node scripts/verify-b.cjs
```
브라우저 스크립트의 기본 경로는 제작 환경용이며 다른 컴퓨터에서는 위 환경변수를 지정합니다. B 검사는 알려진 실패도 JSON에 기록합니다. 앱은 단일 HTML로 별도 빌드·타입체크가 없으며 브라우저 실행과 Node 구문 검사를 수행했습니다.
