# 내 영화 티어리스트

> 사용자가 질문 없이 결정을 위임하여, 제공 아이디어를 바탕으로 AI가 아래 세부사항을 결정했습니다. 사용자와 질의응답으로 정한 것처럼 기록하지 않습니다.

## 누가 쓰나
- 영화를 좋아하는 나와 친구들. 각자 자기 브라우저에서 사용합니다.

## 무엇을 하려고
- 본 영화를 S·A·B·C 등급으로 나누고 취향을 비교합니다.
- 회원가입, 서버, 온라인 공유, 영화 검색 API는 만들지 않습니다.

## 화면과 동작
- S(최고), A(좋음), B(보통), C(아쉬움) 칸과 미분류 칸에 영화 제목 카드를 보여 줍니다.
- 카드를 누른 뒤 등급 이동 버튼을 누르거나 카드를 끌어 놓아 이동합니다. 키보드로도 버튼을 사용할 수 있습니다.
- 제목 입력 후 추가 버튼 또는 Enter로 미분류에 추가합니다. 앞뒤 공백을 없애고 빈 제목·중복 제목·80자 초과 입력을 거부하며 이유를 안내합니다.
- 목록과 배치를 브라우저 localStorage에 자동 저장합니다. 저장 실패 시 저장되지 않았음을 표시하고 현재 화면은 사용할 수 있게 합니다.
- 처음으로 버튼은 확인 후 최초 8개를 미분류로 돌립니다. 취소하면 유지합니다.
- 저장은 같은 브라우저·같은 파일 경로에서만 기대합니다. 파일 이동, 다른 브라우저, 시크릿 모드, 저장 차단 시 보장하지 않습니다.
- 좁은 화면에서도 가로로 잘리지 않으며, 선택 상태·이동 결과·빈 칸 안내가 보입니다.

## 필요한 자료
- 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리.
- 영화 포스터는 쓰지 않습니다. 외부 파일·폰트·통신이 필요 없게 합니다.

## 완성 기준
1. HTML 파일을 직접 열면 최초 영화 8개가 미분류에 보입니다.
2. 기생충을 선택하고 S로 이동하면 S에만 한 번 나타납니다. 다른 칸으로 끌어 놓아도 중복되지 않습니다.
3. 새 영화 제목을 입력하고 Enter를 누르면 미분류에 하나 추가됩니다.
4. 빈 제목·공백·중복 제목·80자 초과 입력 시 영화 수는 변하지 않고 안내가 보입니다.
5. 같은 브라우저에서 같은 파일을 닫았다가 열어도 추가한 영화와 등급이 유지됩니다.
6. 처음으로 확인창에서 취소하면 그대로, 확인하면 최초 8개가 미분류가 됩니다.
7. 390px 화면에서 가로 스크롤 없이 추가·선택·이동할 수 있습니다.
8. 키보드만으로 추가·선택·이동할 수 있고 초점이 보입니다.
9. 저장소가 차단되거나 저장 자료가 잘못되어도 화면이 열리고 문제 안내를 표시합니다.
10. HTML·CSS·JavaScript가 한 파일에 있고 외부 요청 없이 작동합니다.
